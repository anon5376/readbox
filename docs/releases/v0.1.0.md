The first public version of Readbox: a calm read-later app for Mac and Windows with no account and no server. Everything you save is plain files in a folder on your computer.

**What works**
- Save a link by pasting it, or save the page you're on with the browser extension (Firefox, Chrome, Brave, Edge, Helium).
- Read offline in a clean reader with adjustable text, width and page colour (white, sepia, night).
- Import your list from Pocket, Omnivore or Instapaper.
- Keep the library folder in iCloud Drive, Dropbox or OneDrive to sync between computers.

**Download**
- **Mac:** `Readbox_0.1.0_universal.dmg` (Apple Silicon and Intel, macOS 11 or later)
- **Windows:** `Readbox_0.1.0_x64-setup.exe`
- **Browser extension:** `Readbox-browser-extension.zip`. Unzip it, then follow [the install steps](https://github.com/anon5376/readbox#browser-extension).

**Opening it the first time**
Readbox isn't signed with a paid Apple or Microsoft developer certificate yet, so both systems warn you once:
- **Mac:** open the .dmg and drag Readbox into Applications. Open it; when macOS says it can't check it, go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
- **Windows:** if SmartScreen appears, click **More info → Run anyway**.

**Good to know**
This is early software, written mostly by AI coding agents and tested by a human. Expect rough edges, and please [report anything that breaks](https://github.com/anon5376/readbox/issues).
